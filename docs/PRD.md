# Product Requirements Document

## Vision

ContractVault helps users never miss a contract renewal or cancellation date again.

## User Flow

1. User takes a photo or uploads a document
2. AI extracts key information
3. User reviews and confirms
4. Contract is monitored
5. User receives notifications before deadlines
6. User takes action directly from notifications

## Supported Upload Methods

- Camera
- PDF
- DOCX
- JPG
- PNG
- HEIC

## Extracted Information

- Provider
- Contract type
- Price
- Billing frequency
- Start date
- End date
- Auto renewal
- Notice period
- Cancellation deadline

## Notifications

- 7 days before
- 3 days before
- Due date

## Notification Actions

- Keep Contract
- Cancel Contract
- Remind Me Later
- Stop Reminders

## Categories

Optional categories:

- Telecom
- Insurance
- Housing
- Utilities
- Software
- Entertainment
- Gym & Fitness
- Business
- Other
