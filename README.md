# ContractVault

AI-powered contract intelligence.

Users can:

- Take a photo of a contract
- Upload PDF, DOCX or image files
- Automatically extract key contract information
- Track renewal and cancellation deadlines
- Receive proactive reminders
- Take action directly from notifications

## MVP Features

### Upload

- Camera
- PDF
- Image
- DOCX

### Extract

- Provider
- Contract type
- Price
- Start date
- End date
- Auto renewal
- Notice period
- Cancellation deadline

### Notifications

- 7 days before
- 3 days before
- Due date

### Actions

- Keep Contract
- Cancel Contract
- Remind Me Later
- Stop Reminders
